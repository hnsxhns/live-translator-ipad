Mỗi người đăng nhập bằng tài khoản Claude của chính mình: tiền dùng tính vào tài khoản đó, không ai phải chia sẻ key cho ai.

Hướng dẫn lấy API key
  1. Bấm nút cam “Đăng nhập Claude…”. Trang platform.claude.com mở ra trong Safari.
  2. Đăng nhập: chọn Continue with Google để dùng Gmail, hoặc nhập email rồi mở hộp thư bấm vào link / nhập mã Claude gửi. Dùng đúng tài khoản Claude bạn đang có (Pro, Max, Ultra hoặc tài khoản mới đều được).
  3. Lần đầu Claude có thể hỏi tên tổ chức (organization): đặt tên bất kỳ, ví dụ tên của bạn.
  4. Ở trang API keys, bấm Create Key → đặt tên (ví dụ “iPad”) → Create.
  5. Bấm Copy để sao chép key (bắt đầu bằng sk-ant-). Key chỉ hiện một lần: nếu lỡ đóng trước khi copy, tạo key mới.
  6. Quay lại Live Translator (vuốt từ cạnh dưới để đổi app, hoặc chạm “‹ Live Translator” ở góc trên bên trái), bấm 📋 Dán. App tự đăng nhập khi dán đúng key.
  7. Để tick Ghi nhớ đăng nhập: lần sau mở app là vào thẳng.

Tiền dùng

  • API tính tiền theo lượng dùng, tách riêng với gói Claude trên claude.ai. Nạp tiền ở platform.claude.com → Settings → Billing.
  • Gói Ultra có sẵn $200/tháng tiền API: claude.ai → Settings → Billing → API credits → Link organization, rồi tạo key trong đúng tổ chức đó.
  • Dịch ở chế độ “Nhanh (Sonnet)” rẻ hơn nhiều so với “Chất lượng cao (Opus)”.

Gặp lỗi?

  • “API key không hợp lệ”: key bị copy thiếu hoặc đã bị xoá → tạo key mới và dán lại.
  • “Hết credit ($0)”: nạp tiền hoặc liên kết gói Ultra như trên.
  • Nút cam không mở trang: mở Safari, gõ platform.claude.com/settings/keys.
  • Nút Dán không chạy: chạm giữ vào ô nhập key → chọn Dán.

An toàn

  • Key chỉ lưu trên iPad này. Không gửi key cho người khác.
  • Có thể xoá key bất cứ lúc nào ở trang API keys; app sẽ hỏi đăng nhập lại.
